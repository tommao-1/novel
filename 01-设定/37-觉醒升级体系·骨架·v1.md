# 37 · 觉醒升级体系 · 骨架 · v1

> **性质**：觉醒升级体系的**骨架档**（先立体系再完善）。多维度勾连，标 ✅已定 / 🟡骨架 / 🔴缺。血肉（每阶具体技能/武器/坐骑/数值表）待补。
> **设计原则**（知识库 `03-升级与成长`）：① 每次成长给「可感知变化」不加数字 ② 满级不是终点是新起点 ③ 越级认知差才是爽点 ④ 不无限升级。

## 一、体系定位

- **名称**：觉醒升级体系（星宿命格 · 开发度）
- **核心**：开发度 **0-100%** ＝ 觉醒程度，**觉醒即揭秘、随觉醒不随座次**（低序位上限反而更高）
- **接已拍**：星号＝传承（可变量只有开发度 `11-职业体系:155`）· 觉醒技 108 套唯一 · 星宿可收回+重罚（第 35/40 项）· 传承可夺可失
- **与娘山差异**：娘山是双层（降星者修为+星将觉醒）；夺魁主角方砚「不是玩家、就是晁盖/星位本人」（`29-定位建议:59/137`）→ **单层**，主角成长＝开发度。

## 二、升级主轴（一眼看清）

```
开发度 0-100%（唯一成长刻度）
    │
    ├─ 阶位：未觉 0-30% → 半觉 30-70% → 全觉 70-100% → 改命阶 >100%
    │        （觉醒即揭秘：单机 → 揭「非单机」 → 揭「你就是晁盖」 → 改命）
    │
    ├─ 来源：收核化执念（主）+ 战斗刻印 + 星宿共鸣 + 座次竞技
    │        （不靠刷怪，靠剧情/执念）
    │
    ├─ 门槛：认知（懂星宿执念）+ 座次位（低序上限高）+ 契合度（背离则翻车）
    │
    ├─ 解锁：技能（文书→计谋/地形→道法→命格技）
    │        装备（白→紫→红+天命之武）· 坐骑（步行→名马→神驹）
    │        称号（归档吏→星位觉醒者→天魁星·晁盖）
    │
    ├─ 数值：四轴相加（星宿+100~500%随觉醒档 · 职司+20~80% · 法术 · 器物），不互乘
    │
    ├─ 代价/风险：星宿收回+重罚 · 契合度反噬 · 身份暴露 · 死亡倒计时 · 觉醒失控
    │
    ├─ 边界：不无限升级（改命阶新曲线）· 尺度升级替代数值（个人→八寨→国战）
    │
    └─ 节奏：卷一-二未觉（微爽）→卷三-四半觉（越级打脸）→卷五-六全觉（改命）→卷七改命阶（终局）
```

## 四、横向对比（⑩ 补）

> 觉醒不是主角自己涨，是**他在世界的什么位置、和谁比、比出什么认知差**。

| 对象 | 对比轴 | 认知差爽点 | 锚点 |
|---|---|---|---|
| **对手（史文恭线）** | 对手是高序位/高座次、靠资源压制；主角低序位、靠觉醒度 | 低觉醒时被看衰→觉醒后越级打脸 | `31-待拍项` 第 87 项 |
| **盟友（朱仝线）** | 盟友走「规则内晋升」；主角走「觉醒改命」 | 盟友见证主角「不按常理」崛起 | 第 87 项 |
| **反目朋友（吴用线）** | 反目走「招安顺命」；主角走「反宿命改命」 | 路线之争=觉醒路线之争 | 第 87 项 |
| **108 将/NPC** | 108 将有星号但「不觉醒」（星宿工具人）；主角觉醒到「有人性」 | 「让星宿有人性」vs「工具人」 | `02-机制稿` 收核显人性 |
| **天机（公司线）** | 天机按「座次/规则」筛人；主角不争位置争「命」 | 「别人争位置，他在走命」 | `29-定位建议:38` |

## 五、可回退（⑪ 补）

> 觉醒不只涨，还会掉——「传承可夺可失」已拍，接阶位机制。

| 掉阶场景 | 机制 | 后果 | 锚点 |
|---|---|---|---|
| **星宿收回** | 背离契合度/用过度 | 传承回星宿，开发度暴跌 | 第 35/40 项已拍 |
| **传承被夺** | `R2` 座次竞技/强敌夺取 | 开发度归零或转投他人 | 「传承可夺可失」已拍 |
| **契合度反噬** | 背离星宿逻辑 | 加成打折，觉醒技失灵 | 已拍契合度 |
| **觉醒失控** | 晁盖意志压过方砚自我 | 临时掉阶（自我被吞）→ 身份危机 | 第 141 项谜底 |
| **掉阶不是终点** | 掉阶后可重新觉醒（但代价更大） | 防「一掉就废」 | `03-升级与成长:47` 新起点 |

## 六、三阶骨架（血肉待补）

| 阶 | 开发度 | 星号形态 | 揭秘 | 解锁（骨架） | 爽点 |
|---|---|---|---|---|---|
| **未觉** | 0-30% | 黯淡/查不到 | 以为单机 | 文书技/辨伪 · 白装 · 归档吏 | 微爽：理旧档 |
| **半觉** | 30-70% | 渐亮/流转 | 揭「非单机」 | 计谋/地形技 · 紫装+名马 · 星位觉醒者 | 小爽：越级打脸 |

| **改命阶** | >100% | 破格 | 改命 | 命格技 · 镇魔塔重铸 | 终局：打破轮回 |
