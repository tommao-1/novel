### 设计总原则（**`【主人定】` 2026-09-16；与 `3A` / `2A′` 并列，全稿最高约束**）

> **主人原话**：**「异界法则只能通过游戏设定去影响游戏机制，而不能直接影响数值」**

- **三层读法**：
  1. **数值层 = 冻结**（`3A` 不改清单：等级 / 属性 / 爆率 / 副本规则）——**异界法则不能碰，任何能力也不能「面板直改」**。
  2. **机制层 = 唯一入口**——一切影响必须**落在游戏设定里已有的载体**上：**技能 / 状态 / 判定 / 视野**。
  3. **写法要求**：**不能写「对方攻击力 −20」**（对数值层直改）；**要写「施加某状态 → 该状态在机制上导致攻击判定下降」**（经机制层转译）。
- **与 `3A` 的关系**：`3A` 是这条原则在**异界法则**侧的具体化（不改清单）；本原则是**上位表述**，把适用范围从「异界法则」**扩到一切能力**（含妖法）。
- **与 `2A′` 的关系**：属性数值**不会**被外部直改 ⇒ 四轴相加的**封顶不需重算**（`2A′` 的硬顶 / `04-数值体系稿` §十八.1 修法**继续有效**）。
- **落点**：`3A` → §6.4；`11B′`（妖法）→ §三·补 + §6.4；数值侧 → `04-数值体系稿` §4.5。

#### 执行判据（**`【主人定】` 2026-09-16 写死；承上条总原则**）

> **判据原文**：**「不看你『有没有数字』，看你『是否经过可观察、可反制的载体』。」**

| 写法 | 判定 | 为什么 |
|---|---|---|
| **「施加目盲状态（命中率 −10%，持续 8 秒）」** | ✅ **合规** | **经载体**（状态可被看见）+ **可观察** + **可反制**（解状态 / 免疫）；**载体上允许带百分比与持续时间参数** |
| **「对方攻击力永久 −20」** | ❌ **数值直改** | **无载体、不可反制** |

> ✅ **2026-09-16 二次裁定**：**载体上的百分比 / 持续时间参数是被允许的**——判据看的是「**经不经过载体**」，**不是「有没有数字」**。→ 「**目盲（命中率 −10%，持续 8 秒）**」**合规**。

**写每条技能 / 机制时自问三句**：
1. **有没有一个能被人看见的载体**（技能名 / 状态名 / 判定）？
2. **旁观者能不能观察到它生效**（画面 / 面板错乱 / 公告）？
3. **对手能不能反制它**（解状态 / 抵挡 / 换打法）？
→ **三问全过 = 合规；任一不过 = 数值直改，必须改写成经载体的版本。**

> **适用范围与例外（防误读）**：本条管的是**「对他人 / 对世界的影响」**；**自己要变强**（升级 / 装备 / 星位 / 四轴加成）走**系统层**，**不受本条限制**——判据问的是「**你凭什么去改别人**」。
> **参数表达口径（2026-09-16）**：**强度一律用「百分比」或「持续时间」表达**；**「档位 / 6 档表 / 降 N 档」的写法已否决**（见下存档）。

> **存档：原判据 ❌ 例 —— ❌ 已否决（2026-09-16）**（原文照留，不删）：
> **「命中率 −10%」= ❌ 数值直改（无载体、不可反制）** —— 该写法与「**载体上允许带百分比参数**」的新裁定**正面冲突**，故**作废**；正确读法见上表（**带载体的「命中率 −10%」= ✅**）。

### 总则②：进入游戏体系者，一律受游戏规则约束（**`【主人定】` 2026-09-16**）

> **主人原话**：**「参考修罗传说魔将在游戏中也有各项属性，最终 boss 参与到游戏就必须按照游戏规则」**

- **规则**：**凡进入游戏体系的存在**——含**异界魔将 / 最终 BOSS / 神话存在**——**必须有属性面板，必须受游戏规则约束**（可被判定、可被克制、可被结算）。
- **与总则①的关系（互为表里）**：**能碰数值的必须是「体系内的存在」**；反过来说，**体系外的存在不能凌驾规则**——否则「不直连数值」就变成「**只有我方受约束**」。

  1. **BOSS 上场先给面板**（哪怕是残页 / 乱码面板，承 `04` §6.1 模板 A 的「乱码」写法）。

### R2 座次可争（交椅即资源）

**一句话**：座次 = **资源配给权 + 话语权**，可争夺；但**只能在「大事件窗口」重排**（石碣、大征伐、夺权），平时抢座只算私斗。

- **谁和谁对立**：玩家 **vs 玩家**（同一把交椅）；玩家 **vs 组织**（元老占位）。
- **给主角什么麻烦**：入伙即被压在**极低座次**——任务优先权、装备分配、情报知情权全无；硬抢高座会招来**整个组织的敌意**，而非一个人的敌意。
- **破局爽在哪**：在一个大事件窗口里**连跳数级**，并顺手抢到关键岗位（如「走报机密」），从此**信息不对称站到主角这边**。

**例外**：主角可**不走排位走「职司捷径」**——凭 `设计稿` §8.2 ①`职司（等级与岗位解耦）`先占关键岗，再回头升座次（承 `总表` §二·`09-关系图谱`「座次≠职司」）。
**代价**：占哪个岗，就**锁定对应势力的对立线**（终身敌对一线）；且重排窗口开启时，主角会被**多线围攻**（岗上得罪的人集中清算）。

### R3 投名状（入伙契约 × 阵营互斥）

**一句话**：进任何势力都要交**投名状**（限时物证任务），而物证**必然得罪另一个阵营**——**「阵营完全自选」的代价，由投名状兑现**。

- **谁和谁对立**：玩家 **vs 玩家**（阵营对立）；玩家 **vs 自己**（`设计稿` §8.4 ③`忠义双值轴`）。
- **给主角什么麻烦**：第一份投名状就**永久得罪一大势力**；想两头讨好 = 两头都不收；且投名状是**限时**的，选错就没有第二次。
- **破局爽在哪**：一次投名状**同时**拿到①势力信任（解锁该势力传承）②`设计稿` §8.2 ①`招募链（入伙动因）`的**入伙类型专属技**——一次动作两份收益，且**这是他自己选的路**。

**例外**：主角可用**伪造物证**过关（承 `设计稿` §8.2 ①`变装伪装（潜入）`、`总表` §二·`01-原著`「伪造文书·摹写笔迹」）。
**代价**：① 被识破 → **该阵营永久敌对 + 通缉度跳档**（`设计稿` §8.3 ②`赏格 → 通缉系统`）；② 伪造过一次之后，**后续所有「验真」检定难度永久上调**。

### R4 天书·一次性攻略（不可外泄）

**一句话**：BOSS / 秘境的「唯一正解」只能从**天书**取得；**共读、焚毁、不可外泄**（`总表` §二·`01-原著`「天书·神授攻略」）。

- **谁和谁对立**：主角 **vs 全服玩家**（信息垄断 vs 公开）；主角 **vs 队友**（信任）。
- **给主角什么麻烦**：拿到唯一正解却**不能公开**（一公开即焚毁/失效），而队友正逼他共享；不说 = 被疑独吞，说了 = 攻略报废。
- **破局爽在哪**：用独家信息完成**首名 / 越级通关**，全服公告（承 `04-数据与数值` §6.3 三连击：公告 → 争抢 → 示好）。

**例外**：天书**只认主角**（神授，承 `设计稿` §8.2 ①`天书/神授秘笈`）。
**代价**：① **破戒即失效**——外传、食荤等（呼应 `设计稿` §8.2 ①`甲马（消耗式位移）`的「食荤失灵」同源禁忌）；② **每读一次，异界法则显现度上升一格**——攻略本身就是异界的入口（接 §六，这是全稿最重要的一根线）。

### R5 恩义债（可消耗、可继承）

**一句话**：恩怨必偿、**可继承传递**（`总表` §二·`04-设定`「义气·恩怨债」）；「债」既是枷锁，也是主角**唯一能主动消耗的再生资源**。

- **谁和谁对立**：玩家 **vs 玩家**（欠债链）；玩家 **vs 势力**（人情网）。
- **给主角什么麻烦**：开局就欠下一笔**跨数十回的大债**（救命 / 私放之恩）；债主上门讨债时，偿还 = **放弃当前路线**，不还 = `设计稿` §8.3 ②`江湖规矩七条`的**背叛禁忌**（不可赎，全阵营仇恨）。
- **破局爽在哪**：把「债」**反过来用**——消耗一格恩义换**一次免死或一次必杀**，或把债转成**一支可调用的援军**；读者爽在**主角把人情炼成了武器**。

**例外**：只有主角能把恩义债**当主动技消耗**（承 `设计稿` §8.2 ①`恩义债（可消耗资源）`）。
**代价**：消耗后该恩义**永久清空**，对应关系人**转为仇敌**；且消耗满三格触发**「寡恩」标记**——**再无人愿意赊欠给他**（援军断供）。

**出牌节奏**（三层，节拍器是 `总表` §二·`02-回目`「一回＝一张事件牌」）

| 层 | 长度 | 内容 | 纪律 |
|---|---|---|---|
| **微循环** | **1 章** | 一个**可命名的爽点**（首名 / 打脸 / 爆装 / 抢岗） | 一章具体数字 **≤3 个**（`04` §0） |
