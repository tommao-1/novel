## 三、信息圈定义（谁看得到什么 · 照 `第三人称` §4.4 + `叙事件` §4.2）

| 信息圈 | 看得到 | 看不到 |
|---|---|---|
| **方砚（主角）** | 全部主线；自己是晁盖（但**他自己不知道**，第 137 项误解的根） | 谜底（前 3 卷不出）、真凶、幕后 |
| **他者（NPC/玩家）** | 游戏 ID「玲珑塔灵笼」、行为、名声 | 方砚真名、晁盖身份、现实线 |
| **读者** | 方砚现实线 + 游戏线（主角视角 ≥80%） | 谜底分层释放（第 4 卷起才给来源碎片） |

> **谜底接口**（`待批` 第 22 项）：前 3 卷只允许「游戏 ID 出名」，**不允许「真名与 ID 的谜底级对撞」**。

## 五、5 条 POV 规则（照 `14-叙事件` §4.1 视角纪律，交稿逐条打勾）

- [ ] 一场景一锚点
- [ ] 不写他人内心
- [ ] 无 head-hopping（视角乱跳）
- [ ] 场景切换有分隔标记
- [ ] 视角人物不超限（≤2–3，主角 ≥80%）
- [ ] 每次切换有利可图（不为切而切）
- [ ] 不写主角不可能知道的事
