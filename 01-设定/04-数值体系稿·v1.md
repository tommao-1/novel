### 4.6 轴归属表（✅ **乙-01 清账新增，2026-09-16**）—— 一条加成只落一条轴

> **问题**（`05-评估·整体审计` **P7 / C9**）：同一来源被两条轴**重复计入**（① 道法轴区间 **+50%~+200%** 与隐藏职业强度 **+90%~+200% / +380%~+600%** 并存、未说叠加还是替换；② **称号 × 兵器绑定**同时挂在③称号轴与 §6.5 单列项）；且全稿**无「轴归属表」**。
> **规则**（与 §十八.1 第 3 条「**同源不叠**」对齐）：**一条加成来源只落一条轴**；同一物最多给**一条轴**贡献数值，其余影响**一律走机制 / 权限层**。

| 加成来源 | **落哪条轴** | 不落哪条轴 / 备注 |
|---|---|---|
| **星号（＝传承）** 给的属性加成 | **① 星宿加持**（§4.1） | 不再计入其他轴；**开发度**只决定**该轴加成的释放比例**（§5.1、`机制稿` §一 开发机制块），**不新增数值** |

### 9.2 内部校验公式（**仅作者可见**）

```
战力 W = Σ( 一级属性 × 权重 ) × ( 1 + 轴系数和 ) × ( 1 + 装备系数 )
权重建议：力 2.0 / 巧 2.0 / 谋 1.5        ✅ **主人定（第 128 项 · 2026-09-18）**
轴系数和 = 四轴加成之和（§四；**`2A′`：跨轴相加，轴内基础 + %**）
装备系数 = 品级链 + 强化 + 套装（§六）
```
**用途**：只用于估「两人差多少」，**防「1 级秒 100 级」这种读者一眼看出的假**（承 `04` §2.2 写作动作 3）。

## 十四、写作层数值纪律（承 `04-数据与数值` §0、§6）

### 14.1 四条铁律（`04` §0，直接执行）

1. **少而精**：**一章具体数字 ≤ 3 个**（含面板行里的数字）——**超了删**。
2. **有对比**：数字的意义来自「比别人高多少」，不来自绝对值。
3. **有情绪**：数字挂在**人的反应**上，不挂在系统播报上。
4. **有画面**：能写成画面的数字，就别写成表格。

### 14.2 数字必配参照物（`04` §0 心法）

**改写公式**：`数字 → 参照物 → 人的反应`。

| 枯燥版 | 好看版 |
|---|---|
| 攻击力 5000 | 这一刀够把穿新手装的人连皮带甲劈开，只差一个刀法 |
| 暴击率 35% | 三刀里有一刀，是天意 |

### 14.3 面板出现频率（`04` §1.2 / §6.1）

- **只在「有变化」时出现**（升级 / 换装 / 觉醒）；**一次 ≤ 8 行**

## 十八、最容易被写崩的三处数值（小萌判断，可推翻）

### 1️⃣ 四轴加成的**乘算叠加**（§四 + §六 + §九）

**为什么最危险**：四轴**天然可叠加**（一把法器能同时算「器物 + 道法 + 兵器绑定称号」），若全按**乘法**，`1.2 × 2.0 × 1.5 × 1.5 × 1.3 × 1.2 × 1.3 ≈ 13 倍`；再叠套装 / 强化 / 阵形，**Lv100 可以到 10⁴ 倍以上**——**这就是「战力崩坏」的数学源头**。
**症状**：前 60 级还正常，中后期「一招秒全场」。
**修法（✅ 已按 `2A′` 落定 + 五条一起上）**：
1. **跨轴相加、轴内「基础 + 百分比」**（`2A′`）——**不再允许四轴互乘**
2. **乘法源 ≤ 3，且每个设硬顶**（`2A′`）：全稿只留 **克制 × 暴击 × 地形** 三个（§三.1），各设上限；**其余一律相加**
3. **同源不叠**：同一轴 / 同名词条内**取最高**，不累加
4. **轴总和设上限**：✅ **已拍（第 64 项）**：**`+300%` ＝ 普通职业的顶**〔原：`【依主人拍板】` 建议 **+300% 封顶** · 已修 2026-09-18〕（超出部分转为「机制 / 权限」，不转战力） 〔标记已同步 2026-10-11：已拍/已裁/已定，原标记留痕〕
5. **高段位靠机制不靠数值**（承 `04` §7.4 修复动作 2 / 3）
6. **隐藏职业单列上限**（`8C-2` + 第 12 项新增）：**隐藏职业不并进**普通职业的 +300% 总上限，**另设「隐藏上限」**（✅ **已拍（第 64 项）：`+450%`，上沿不取 `600%`**）〔原标 `【依主人拍板】` · 已修 2026-09-18〕（`【建议】` +450%~+600%）；**两套上限须一次拍定**（§4.5、§十七 #19） 〔标记已同步 2026-10-11：已拍/已裁/已定，原标记留痕〕
   > ✅ **注（2026-09-16 终裁后）**：属性数值**不会被外部直改**（总原则）⇒ **封顶体系不需重算**（三解中的 `13B`「修正 `3A`」已作废，其账单随之解除）。

### 2️⃣ 双轨货币的**锚点与通胀**（§八）

**为什么最危险**：`04` §7.5 点名的「读者最恨」——**第 3 章 1 万贯是巨款，第 80 章不够买碗面**。本作**双轨并行**（贯 / 金珠），**~~换算率还 `【待考】`~~ 已修（2026-09-16）**：**框架 ✅ `6D` 已定**；**具体比例仍属小萌建议**（`D8` 待主人确认：1 元 = 10 文 / 100 元 = 1 贯，双边价差 **20%**（以买价为基准；原写 ≈15% 已修 2026-09-16 · 乙-16），见 §8.1）——**原值「待考」已过期，保留可见**；此处**仍留一处可漂移口**：`贯 ↔ 两 ↔ 锭` 的**内部进位细目**待补（§十七 #1）。
**症状**：拍卖行的数字越来越大，读者从震惊到麻木；「三万贯的雁翎锁子甲」变成笑话。
**修法**：① **锚点先行**（§8.2 表一次拍定，之后只做**等比**调整）② **每卷回填台账** ③ **通胀必须有剧情原因**（版本更新 / 四大征伐消耗），**没有原因的通胀 = 吃书**

### 3️⃣ `R4` 天书的**显现度格子**（§十二.1）

**为什么最危险**：它是全稿**唯一的明面进度条**，**同时控制爽点与悬念**——
- 读太快 → 后期提前到，**中段无戏可写**（主导权易手后，游戏规则降格，读者预期漂移）
- 读太慢 → 悬念断，读者忘了这条线
**症状**：中段「异界事件」扎堆，或者整卷提都不提。
**修法**：① **每卷最多读 1 次**（硬上限）② 节点 ✅ **`4 / 7`**（第 31 项 ＋ **第 59 项收口**；**原值 `4 / 7 / 10`、`3 / 6 / 9` 保留可见**），**与卷结构对齐**（每卷末一次异界显形）—— ✅ **对齐表已写死，见 §12.1「格—卷对齐表」（乙-04，2026-09-16）**；③ **满格才易手**——不要在 7 格时就冲掉游戏规则

> **共同根因**：三处都属「**能自己长大的数值**」——一旦写起来就会自己往前跑。**给它们各设一个硬闸门**，比事后补救便宜得多。
