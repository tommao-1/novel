# 语言素材（✅ P2-26 甲 2026-10-01 已拍）

> **主人拍「全甲」（2026-10-01）**，P2-26 甲＝普通话+偶尔山东味 + 切口接机制 + 配角各具语言 + 对话里出现。承 P1-11/15/16 口癖/记忆点。

## 一、主角方言

| 项 | 内容 | 用法 |
|---|---|---|
| **基调** | **普通话为主，偶尔带山东味**（"俺"=偶尔；不堆方言，读者看得懂） | 对话里出现 |
| **山东味词** | 「俺」（我）/「咋」（怎么）/「中」（行）/「得劲」（舒服）/「拉呱」（聊天） | 一章 1-2 处 |
| **反例** | ~~全方言~~（读者看不懂）｜~~纯普通话~~（没味道） | — |

## 二、江湖切口（接库内「切口黑话」机制）

| 切口 | 意思 | 用法 |
|---|---|---|
| **入伙** | 加入帮派/梁山 | 对话里出现 |
| **拜山** | 拜见头领 | 同上 |
| **踩盘子** | 踩点/侦察 | 同上 |
| **点子** | 目标/对象 | 同上 |
| **并肩子** | 朋友/同伙 | 同上 |
| **滑下去** | 逃跑 | 同上 |
| **青子** | 刀 | 同上 |
| **落底** | 暴露/被发现 | 同上 |

## 三、配角各具语言（承 P1-11/15/16）

| 配角 | 语言特征 | 锚 |
|---|---|---|
| **主角方砚** | 「我记一下」/「这事我来吧」/「算了」三句口癖 + 少而准公文气 + 书面语偏多 | P1-11 甲 |
| **朱仝（盟友）** | **短句、不解释**（递纸条时只说「看完了烧掉」/「这事别问」；**从不说「我帮你」**） | P1-15 甲 |
| **吴用（会反目的朋友）** | **句句有理、爱说「依我之见」**（每次开口都是分析利弊；**反目时也不骂人**，只说「你这样会害死大家」） | P1-16 甲 |
| **母亲** | **催问式**（"对象呢"/"啥时候带回来"） | `20-人物弧线` L56 |
| **领导钱主任** | **甩锅式**（"这事你看着办"/"小方啊，这个事..."） | P1-14 甲 |

## 四、落法纪律

- **口癖/方言/切口只在对话里出现**：不旁白解释。
- **一章 1-2 处**：不堆砌。
- **读者看得懂**：方言/切口用**上下文**带出意思，不注释。
