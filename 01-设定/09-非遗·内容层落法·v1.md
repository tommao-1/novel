## 〇、前提与口径（`【主人定】`）

> **主人原话（2026-09-16，`99-待批清单·2026-09-16.md` 第 44 项）**：
> **「不对，这个非遗太过于刻意。关于非遗和文化部分可作为游戏内容在书中自然体现。」**

**三条处置（第 44 项已记，本稿不重述理由）**：

| # | 口径 | 本稿落点 |
|---|---|---|
| 1 | 三张主角卡（说书人 / 水浒拳 / 纸牌水浒）**均不作主线基座** | 本稿**不设"非遗金手指"**；`01-设定/08-主角设定建议·v1.md` 文末裁定照旧 |
| 2 | **主角回到「普通玩家」基座**——星号传承 ＋ 座次竞技 ＋ 开发度（承第 34 / 37 / 42 项） | 本稿**不碰主角能力轴**，与 `设计稿` §6.5 / `机制稿` §一 `R1` 对齐 |
| 3 | **非遗 / 文化 → 游戏世界的内容层**：门派 · 技艺 · NPC 手艺 · 副本规则 · 道具来源 · 节令 | **本稿 §一 六位置逐一定铺** |

**本稿三条自制纪律**（承 `机制稿` §0 设计总原则）：
1. **非遗不提供"只有主角能拿到"的东西**（否则立刻退回第 44 项否定的写法）。
2. **非遗不占招牌位**——`R1`–`R5` 已满（第 41 项 `R6` 不破例），非遗全部落在 `机制稿` §三「八类机制」内当零件。
3. **非遗不碰 `3A` 不改清单**（等级 / 属性 / 爆率 / 副本规则）——副本里的"非遗解法"必须走**机制层**（状态 / 判定 / 视野），承 `机制稿` §0 与执行判据。

**非遗十大类别**（（已删） §一 附）：民间文学 · 传统音乐 · 传统舞蹈 · 传统戏剧 · 曲艺 · 传统体育游艺与杂技 · 传统美术 · 传统技艺 · 传统医药 · 民俗。

## 一、六个位置逐一定铺

> **列义**：位置 ｜ 放什么非遗（**具体项目名**）｜ 库内素材（文件 + 节/行）｜ 原著/回次 ｜ 做成什么玩法 ｜ **怎么"自然体现"**（不喊口号的具体写法）。
> **通用口径（六表共用，不再逐行重复）**：
> - **非遗项目名与级别**一律照 `00-题材库/游戏/99-非遗选题参考·水浒相关.md` §一（下称 `99-非遗`）；**标「待考」者本稿只作民俗 / 背景，不作级别宣称**。

## 二、知识准确度要求（这是征文"知识准确 + 深度"的落法）

> **征文硬条款**：主题 = **以非遗为代表的中华优秀传统文化**，需**知识准确 + 深度**（（已删） §一）。
> **本稿的落法**：**准确**落在"**能用库内文件核到**"，**深度**落在"**能顺着指针一路查下去**"——两者都不是形容词。

### 2.1 三级分级

| 级别 | 含义 | 判据 | 本稿范围 |
|---|---|---|---|
| **A · 必须真** | **写错即减分**；被读者 / 评委 / 行家一眼看破 | **库内有能力核**（原文回次可 grep、名录级别有官方口径） | 原著用字与回次 · 底本异文 · 非遗级别与申报地 · 江湖切口与称谓 · 节令事象 · 器物形制 |
| **B · 可虚构但须自洽** | 可以自造，但**不能自相矛盾**，且须**能反推真实原型** | 与 `机制稿` §0 总原则 / `2A′` / `3A` 不冲突 | 游戏内门派名 · 副本规则 · 技能名 · 数值 · 非遗在本世界的传承谱系（有官方说法者照说，无者标 `【建议】`） |
| **C · 可艺术夸张** | 允许放大，但**不越 `机制稿` §0**（不改数值层） | 承 `设计稿` §1（神话加强）+ `10-器物/00` §一（器物描写"多带道具化色彩"） | 武力表现 · 法术特效 · 器物 / 马匹表现 |

### 3.2 为什么这种更稳（对照 `01-设定/08-主角设定建议·v1.md` 的教训）

> **`08` 的原文教训**（该稿文末「⚠️ 主人裁定」）：**「非遗太过于刻意」** → 三案（说书人 / 水浒拳 / 纸牌水浒）**均不作主角核心**。

| 对照项 | **08 三案（非遗 = 金手指）** | **本稿（非遗 = 内容层）** |
|---|---|---|
| 非遗在世界里的位置 | 主角的**身体 / 能力** | 世界的**材质** |
| 谁在用 | **只有主角** | **所有玩家与 NPC**（人人可入门派、可酿酒、可听书） |
| 要不要解释 | **必须解释**"这为什么算非遗" → **解释 = 喊口号** | **不需要解释**——东西自己会说话 |
| 深度来源 | **单个项目**（山东快书） | **项目群**（本稿六位置 **31 条落点**） |
| 写错的代价 | **能力设定崩**（"唱错一字不生效"要求 100% 准确） | 一个背景细节，**容错高** |
| 与主人口径 | 与「**主角 = 普通玩家**」冲突（非遗成了唯一性优势） | 与第 **34 / 37 / 42** 项**完全对齐**（主角仍靠星号传承 + 座次 + 开发度） |
| 被判定"刻意"的风险 | **高**（主人原话已定性） | **低**（非遗在世界里，**不在主角身上**） |

> **一句话**：`08` 把非遗做成**主角的判据**，本稿把非遗做成**世界的判据**。前者要**证明**非遗的价值（证明 = 刻意），后者只需**让非遗在场上运转**。
