## 概念详解（原 6 概念页正文并入）

### 夺魁 / 魁首
- **一句话**：「魁首」＝ 运营方「天机」设的奖（暗线）——全服争的是**宋江位（天魁星·魁首）**，而主角走的是**晁盖的生平** → ⭐ **别人在争位置，他在走命**。
- 源头 → [[项目-夺魁/01-设定/32-游戏世界观设计稿·v1|世界观稿]] §二（`L27`）｜同源 → [[项目-夺魁/01-设定/12-主角与开局·v1|主角与开局]] `L50`｜书名 → [[项目-夺魁/01-设定/16-开书设定件·v1|开书设定件]]
- 关联：天机（设奖者）｜三人位（承载者）｜谜底分层（「走命」的真相）

### 三人位
- **一句话**：「三人位」承担者一律＝**玩家**，原著人物＝**传承原型**——「这是一本网游小说，更多是玩家之间的竞争」，故三人位由玩家获得史文恭传承来承担。
- 源头 → [[项目-夺魁/01-设定/14-叙事件·v1|叙事件]] §1.2 / §1.1（2026-09-18 确认 1）

### 传承
- **一句话**：「传承」是能力/座次的**承载机制**——玩家获得某原著人物（如史文恭）的传承，即承接其能力轴与座次位；是网游设定里把「水浒人物」转成「可玩角色」的核心接口。
- 源头 → [[项目-夺魁/01-设定/35-能力维度总表|能力维度总表]]（19 板块 · 约 253 条能力/传承轴）

### 天机
- **一句话**：「天机」是游戏运营方（暗线）——它知道这一局的真相，设「魁首」正是为了**筛选 / 观察**；与第 137 项 ②丙「不该存在的入口」同源。
- 源头 → [[项目-夺魁/01-设定/32-游戏世界观设计稿·v1|世界观稿]] §二（运营方暗线，`L27`）

### 座次 / 星宿
- **一句话**：「座次带」是双进度器 **B**——地煞(37–72) → 天罡(13–36) → 核心(1–12) → 排序者换人；「星宿归位」是卷七的终局兑现。座次带 + 星宿 = 全书实力/地位刻度。
- 源头 → `数值稿` §11.2

### 谜底分层
- **一句话**：全书谜底分层揭底——第 1 层「以为是晁盖传承，其实是晁盖（剧情＝晁盖生平）」；第 2 层多人触发 → 延后至卷四起；第 3 层身份 → 更后。逐层误解各留钩子。
- 源头 → [[项目-夺魁/01-设定/14-叙事件·v1|叙事件]] 第 22 项（谜底）· 第 141 项（晁盖生平）
